Overview

Tethur USD (USDT.) is a clean, modern USD-linked ERC-20 style digital asset created with transparency, fixed supply, and educational value in mind. Built on the Ethereum blockchain, Tethur USD provides a simple, verifiable, and fully immutable contract structure with no owner privileges, no mint function, and no external hooks.
