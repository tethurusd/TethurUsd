Overview

Tethur USD (USDT.) is a clean, modern stable-asset representation built on the Ethereum blockchain. Designed for educational and demonstration purposes, it provides a premium and transparent ERC-20 experience with 6-decimal precision.

This project is not affiliated with Tether or any other existing stablecoin issuer.

How to View / Import

  • Open your Web3 wallet (e.g. MetaMask, Trust Wallet).
  • Make sure you are on the Ethereum network.
  • Use the "Import Token" / "Add Custom Token" option.
  • Paste the contract address above into the token contract field.
  • Decimals: 6, Symbol: USDT. (usually auto-fills).
  • Confirm and save to see your Tethur USD balance.
